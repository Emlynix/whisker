Fixes from the first bug reports, and an easier way to send the next ones.

## Fixed

- **"Change mouse" froze the window** for seconds with several wireless
  receivers connected (#1). The dialog now opens at once and fills in
  when the mice are found. Thanks to @therealMKD for the report and the
  fix (#5).
- **Error in the Windows event log on exit** (`0xc000000d`, #1): closing
  Whisker with its window open ended with an application error. Also
  fixed in #5.
- The suggested catalogue entry in a mouse report named the receiver
  ("USB Receiver") instead of the mouse.

## Changed

- **Tray icon:** the window opens on a double click, not on a single
  one (#6). The tooltip still shows the battery.
- **Logitech M510** is listed as supported (#4).

## New: reporting problems

- **Diagnostic log.** Whisker keeps a small log on your computer:
  start-up, mice found, what the driver did, crashes and hangs. Open it
  under *Settings → Mouse → Diagnostics → Show log*. After a crash or a
  hang Whisker offers it on the next start.
- **Send.** The mouse report (*About → Help add your mouse*) and the log
  can be sent to the developers with one click. You see the whole text
  first, and nothing is ever sent without that click. You get a report
  ID to quote in a GitHub issue.
- **Logitech mice:** the report now lists the HID++ features of the
  mouse and whether it runs its onboard profile (#2).

The log holds no serial numbers, Bluetooth names, key presses or
clicks. Sent reports are kept for 12 months. See *Privacy* in the README.

## Download

| System | File |
|---|---|
| Windows 10 / 11 (x86-64) | `whisker-windows-x86_64.exe`: run it, no installer needed |

with the Whisker release key.
