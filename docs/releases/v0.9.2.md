A new look, profiles, and a fix for Logitech mice on a Unifying
receiver.

## New

- **New design.** A fixed 800 x 600 window with its own title bar, a
  status bar for connection and battery, sharp controls, Inter and
  JetBrains Mono. Every page is laid out anew. About is a tab of
  Settings.
- **Profiles.** A profile is a named button layout with its macros.
  Make, copy, rename and delete them on the *Profiles* page; switch
  there, on *Overview* or from the tray menu. Each mouse has its own
  profiles.
- **Profiles by app.** A profile may name a program and works while
  that program is in focus. Not available under Wayland.
- **Export and import.** Write the active profile or all of them to a
  file and read them back, also on another computer.
- **Several mice.** Whisker remembers every mouse you have chosen and
  switches to one when it is connected, or when the current one is
  gone.
- **Text mode.** The `>_ TUI` button in the title bar, or F10, draws
  the whole window as a terminal screen. Keys 1-9 open the pages.
- **Buttons page.** The mouse is a 3D drawing built from the button
  layout of your model: side, top and grid buttons, tilt wheel, thumb
  wheel.
- **Tray icon.** The Whisker logo fills with the battery charge: green,
  amber, red; blue while charging.
- **Effects.** Background texture and animations, both switchable under
  *Settings → Appearance → Effects*.

## Fixed

- **Logitech mice on a Unifying receiver** could lose their name and
  battery and flap between online and asleep. The driver took the reply
  to the previous request for the current one.
- A silent non-mouse device on a Logitech receiver could be opened as a
  mouse.

## Changed

- Themes are Dark, Light, Tokyo Night and Dracula. A removed theme
  falls back to the system one.
- The language is chosen under *Settings → General*.
- Pages marked PRO preview Whisker Pro. They do nothing here.

## Download

| System | File |
|---|---|
| Windows 10 / 11 (x86-64) | `whisker-windows-x86_64.exe`: run it, no installer needed |
| Linux (x86-64, GTK 3), experimental | `whisker-linux-x86_64`: `chmod +x`, run; the app shows how to grant mouse access |

Whisker 0.9.0 and newer update themselves. Every file has a `.sig`
signature made with the Whisker release key.
